## Required canonical ordering

The generic experiment preflight shall use fail-closed composition.

R6H_PREFLIGHT_ORDER_1=PLATFORM_READINESS
R6H_PREFLIGHT_ORDER_2=PORTABLE_RUNTIME_ADMISSION
R6H_PREFLIGHT_ORDER_3=GENERIC_PREFLIGHT_FINAL_ADJUDICATION

Required control flow:

PLATFORM_READINESS_PASS_REQUIRED=YES
PORTABLE_RUNTIME_ADMISSION_PASS_REQUIRED=YES

If platform readiness fails, portable experiment execution shall not be
admitted.

If portable-runtime admission fails, experiment execution shall not be
admitted.

R6H_GENERIC_PREFLIGHT_PASS_REQUIRES_ALL_REQUIRED_PROVIDERS_PASS=YES
R6H_GENERIC_PREFLIGHT_FAIL_CLOSED=YES

## Experiment-specific boundary

Prompt-12-specific admission remains separate from the generic experiment
preflight.

The following responsibilities are not generic-preflight responsibilities:

- Prompt-12 output-stationarity admission;
- Prompt-12 precontrol freshness;
- actuator command admission;
- applied/readback validation;
- scientific workload generation;
- active user-plane smoke evidence production;
- PRB control;
- scientific trigger execution.

R6H_PROMPT12_SPECIFIC_COUPLING_IN_GENERIC_PREFLIGHT=FORBIDDEN
