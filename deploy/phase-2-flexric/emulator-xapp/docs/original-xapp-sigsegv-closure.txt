ORIGINAL DEFECT
---------------
Release xapp_oran_moni terminated with SIGSEGV while processing
E2SM-KPM measurement records.

ROOT CAUSE
----------
sm_cb_kpm() indexed meas_info_lst[z] when z was bounded only by the
measurement-record length. Runtime evidence showed:

  z = 2
  meas_record_len = 4
  meas_info_lst_len = 2

The access was therefore outside meas_info_lst.

CORRECTION
----------
The condition was changed from:

  meas_info_lst_len > 0

to:

  z < meas_info_lst_len
